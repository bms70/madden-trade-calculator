How to Use

  1. Add assets under the team receiving them. Each side supports up to six assets.
  2. Select Player or Draft Pick. Player valuation requires OVR, age, position, and development trait; optional blanks use neutral defaults.
  3. Completed cards collapse automatically. Expand a card to edit it; the calculator preserves the expanded/collapsed state while values recalculate.
  4. Review Individual Asset Value on each card, then Raw Package Value and Adjusted Package Value concepts in Trade Analysis. Adjusted Package Value applies the six-slot package credits and drives the verdict.
  5. Use Primary Read to understand the governing rule and Suggested Correction for the exact side/value change needed.

Result terminology

  • Individual Asset Value: the asset's full-precision value before package compression.
  • Raw Package Value: the sum of Individual Asset Values received by a side.
  • Adjusted Package Value: ranked package value after the 100/90/75/60/50/50 credits.
  • Adjusted Gap: relative difference between the two Adjusted Package Values.

Common trade types

Player/mixed: the higher eligible positive-value Player determines the protected acquisition side. Standard, Cornerstone, or Elite QB protection sets the directional target.
Exact Player-value tie: protection tier does not break a cross-package tie; the 8% Adjusted Gap path applies.
Draft-only: the stronger pick can trigger 1.15x, 1.08x, 1.04x, or 1.00x protection with the 8% acceptance window.

Common mistakes

  • Entering assets under the team sending them instead of the team receiving them.
  • Leaving required Player fields incomplete and expecting Player value/protection.
  • Judging a boundary from the rounded display. Verdicts use full internal precision.
  • Using protection tier to break an exact Player-value tie across packages. Tier precedence is only a same-package tiebreak.
Blank Years in League, Years Remaining, roles, and cap hit use neutral/default behavior. Blank draft timing means Current draft.

Ruleset v4.2

Player/mixed protection uses the highest eligible positive-value Player in each package. Same-package exact-value ties use Elite QB > Franchise Cornerstone > Standard, then input order. Cross-package Player ties require exact full-precision equality and use the 8% Adjusted Gap path.

Directional acquisition protection

  • Standard: 1.10x required return.
  • Franchise Cornerstone: age 26 or younger, 87+ OVR, Superstar/X-Factor; 1.20x required return. Individual scarcity remains 1.25x.
  • Elite QB: QB, age 26 or younger, 90+ OVR, Superstar/X-Factor; 1.30x required return.

Directional FAIR requires Counter-Package from Required Target through Required Target × 1.08, inclusive. If both positive packages have no eligible positive-value Player, the 8% Adjusted Gap path applies.

Draft-only

Acquire 1.01: 1.15x; 1.02/1.03: 1.08x; meaningful trade-up: 1.04x; lateral/near-lateral: 1.00x. Applicable target through +8%.

Fallback verdicts

Not FAIR: gap under 12% QUESTIONABLE; 12% to under 22% UNFAIR; 22% or more LEAGUE-BREAKING.
